# DragonPet 🐉 — تنين سطح المكتب الذكي

حيوان أليف افتراضي على شكل **تنين صغير** يعيش على سطح مكتب Windows، يتصرّف بدلال،
يساعدك في المهام، ويشتعل ناراً عند حدوث أي خطأ. مبني بلغة **Python + PySide6**
والرسوم كلها مرسومة برمجياً (بدون صور خارجية) لتكون خفيفة وسلسة.

## المزايا الحالية

- **نافذة شفافة دائمة في المقدمة** — التنين يتجوّل على سطح المكتب ويمكن سحبه بالفأرة.
- **مزاجات متحركة**:
  - خمول: يتنفّس، يرمش، يتثاءب ثم ينام عند تركه.
  - سعادة مبالغة عند نجاح مهمة (قفز واهتزاز).
  - **اشتعال ناري 🔥 عند أي خطأ** (فشل أمر أو استثناء غير معالَج في التطبيق).
  - طيران للبحث، وضع تيرمنال (لون قوس قزح)، توهّج أخضر عند التثبيت.
- **شاشة مشاعر على الصدر** تعرض emoji حسب المزاج، و**عيون تتغيّر لونها** حسب الحالة.
- **تنفيذ الأوامر** (عربي/إنجليزي): فتح تطبيقات، بحث في الويب، البحث عن ملفات،
  تنظيم المجلدات، تشغيل PowerShell، وإنشاء ملفات كود.
- **حماية ملفات النظام**: يرفض أي عملية على `C:\Windows` و`Program Files` وغيرها.
- **ذاكرة سياق** تتذكّر أوامرك المتكررة وتقترح اقتراحات ذكية
  ("تريد فتح Chrome؟ أنت تستخدمه كثيراً").
- **تكامل AI اختياري** عبر OpenAI أو Ollama لفهم الأوامر الطبيعية،
  مع بديل قائم على القواعد يعمل دون إنترنت.

## التشغيل

```powershell
cd dragon-pet
pip install -r requirements.txt
python main.py
```

- **نقر مزدوج** على التنين (أو زر يمين ← "أعطِ أمراً") لكتابة أمر.
- **زر يمين** يفتح قائمة: أمر، إطعام، الحالة، إغلاق.

## الأوامر المدعومة (أمثلة)

| المثال | النتيجة |
| --- | --- |
| `افتح كروم` | يفتح Chrome |
| `ابحث في الويب عن أفضل محرر أكواد` | يطير ويفتح بحث Google |
| `ابحث عن ملف تقرير` | يبحث في Desktop/Documents/Downloads |
| `نظم مجلد C:\Users\me\Downloads` | يرتّب الملفات في مجلدات حسب النوع |
| `powershell Get-Date` | يشغّل الأمر (وضع قوس قزح) |
| `اكتب كود my_app/main.py` | ينشئ ملف بداية |

## التكامل مع AI (اختياري)

```powershell
$env:OPENAI_API_KEY = "sk-..."      # أو استخدم Ollama محلياً
$env:OLLAMA_HOST = "http://localhost:11434"
```

بدون أي مفتاح يعمل التنين عبر مُحلّل الأوامر القائم على الكلمات المفتاحية.

## البنية

```
dragon-pet/
  main.py                     نقطة الدخول
  dragonpet/
    states.py                 المزاجات + ألوان العيون + emoji
    dragon_widget.py          رسم التنين المتحرك (QPainter)
    pet_window.py             النافذة الشفافة + الحركة + التفاعل
    speech_bubble.py          فقاعة الكلام
    assistant/
      commands.py             محلّل النوايا + منفّذ في خيط منفصل
      system_tasks.py         فتح تطبيقات / PowerShell / تنظيم + حماية النظام
      web_search.py           بحث ويب + بحث ملفات
      memory.py               ذاكرة السياق + الاقتراحات
      ai_brain.py             OpenAI / Ollama
      code_tools.py           فحص/إصلاح كود + قوالب
  tools/
    render_preview.py         تصدير صور لكل مزاج
    smoke_test.py             اختبارات منطقية بدون واجهة
```
